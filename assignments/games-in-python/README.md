
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa o clássico jogo de adivinhar palavras em Python, praticando manipulação de strings, loops, condicionais e entrada de dados do usuário.

## 📝 Tarefas

### 🛠️ Exibir a palavra oculta

#### Descrição

Crie a estrutura inicial de um jogo da Forca que escolha uma palavra aleatória e exiba o progresso das letras adivinhadas.

#### Requisitos

O programa concluído deve:

- Selecionar uma palavra aleatoriamente de uma lista predefinida
- Aceitar palpites de letras
- Mostrar as letras descobertas e representar as letras restantes como `_`

### 🛠️ Completar o jogo da Forca

#### Descrição

Expanda o jogo para acompanhar os palpites incorretos e encerrar a partida quando o jogador vencer ou esgotar as tentativas.

#### Requisitos

O programa concluído deve:

- Rastrear e exibir as tentativas incorretas restantes
- Encerrar quando a palavra for adivinhada ou as tentativas se esgotarem
- Exibir uma mensagem de vitória ou derrota
